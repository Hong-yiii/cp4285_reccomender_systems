# Progress updates

One dated file per team share, written in the same shape as the meeting notes so updates and meetings read alike:

1. Title and date.
2. A one-line summary.
3. Topic sections of short bullets. Every number links to the document or artifact it comes from.
4. **Next steps**, one line each: `[Owner] Task: description`. Owners default to `[The group]` until the team assigns them.

Keep implemented results, team decisions and proposals distinct, as `AGENTS.md` requires. Mark anything taken from machine-generated meeting notes as unconfirmed.
