# STePS page images

These are the images on our [UVENTS project page](https://uvents.nus.edu.sg/event/29th-steps/module/CP4285/project/3), which only accepts image links. The page links to these files at a fixed commit, so keep that commit in the history or the images will break.

| File | Shows |
| --- | --- |
| `1-animation.gif` | Main image: Keyboards & MIDI rises, fades and falls, with the flower reacting |
| `2-comic.png` | The same story in four panels |
| `3-overview.png` | One poisoned update, then three clean ones |
| `4-forgetting.png` | Forgetting only shows up at the product level |
| `5-attack-types.png` | Attack strength and fraud-check scores |
| `6-dose.png` | Attacks start working at around 1% of an update |
| `7-who-it-affects.png` | The attack affects everyone, and active accounts work best |
| `8-fading.png` | Most of the effect is gone after three clean updates |
| `9-late-removal.png` | Removing the poisoned adapter late pushes the target below normal |

The animation and comic show one real case: re-listing on Instruments, mean of 3 seeds, drawn from a #10 start. The target gains 6.36 places right after, keeps 0.66 after three clean updates, and sits 4.61 below clean once the adapter is removed. The category names are real, but their order is an example, and the speech-bubble jokes are invented.

The other numbers come from `docs/CONTINUED-TRAINING.md`, `docs/PESO-REPLICATION.md` and `replication/peso/results/grid/lattice.json`.
